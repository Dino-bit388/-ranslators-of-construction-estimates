# СметАналитик

Настольное приложение для анализа строительных смет и прогноза материалов.

Приложение собирает базу материалов из готовых смет и классифицирует их. Инженер-сметчик указывает тип и площадь планируемого объекта и получает список рекомендуемых материалов с примерными количествами, рассчитанными по похожим сметам.

## Как это работает

1. Загружаются сметы в формате Excel (.xlsx). Поддерживаются ЛСР по Методике 2020 и старая форма №4.
2. Из каждой сметы извлекаются материалы. Они группируются по кодам КСР/ФССЦ.
3. Для каждого материала считается расход на 1 м² площади объекта.
4. По введённой площади приложение подбирает похожие сметы и рекомендует материалы и их количество.

Старые сметы по форме №4 учитываются только как подсказка, какие материалы встречаются: точные количества в них неполные.

## Стек

- Python, Flask
- pywebview (окно настольного приложения)
- openpyxl (чтение смет)
- SQLite (локальная база данных)
- PyInstaller (сборка в .exe)

## Состояние проекта

Проект в разработке.

Готово:
- парсер смет для обоих форматов, проверенный на реальных сметах;
- база данных переведена с PostgreSQL на локальный SQLite, сервер ставить не нужно;
- проведено ревью кода, исправлены ошибки загрузки смет.

В работе:
- подключение нового парсера и базы к интерфейсу приложения;
- расчёт рекомендаций материалов по площади.

## Запуск

```
pip install -r requirements.txt
python main.py
```

База данных создаётся автоматически при первом запуске в папке `%APPDATA%\СметАналитик\`.
